# Contributing

Thanks for helping improve Wiring Harness Designer.

## Local Development

1. Open `index.html` in a modern browser or serve the repository with a static web server.
2. Make focused changes to `index.html`, `styles.css`, or `app.js`.
3. Verify the editor, live preview, JSON save/import, and print/export workflows.
4. Open a pull request describing the behavior changed and how it was tested.

## Design Guidelines

- Keep the app usable without a server or account.
- Preserve compatibility with older saved JSON projects.
- Keep DNP rows out of the live drawing.
- Prefer clear, printable harness diagrams over decorative effects.
- Avoid adding external runtime dependencies unless they solve a meaningful problem.

## Reporting Issues

Include the browser version, steps to reproduce, expected result, actual result, and a screenshot when useful. Do not attach confidential harness project files to public issues.
